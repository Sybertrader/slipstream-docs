The missing link

What Monday looks like

Three answers, from the Jira work you already have.

The blocker nobody linked

Blocks links stay when a team remembered them. Slipstream also reads issue keys written in comments and descriptions, including branch, pull-request, or commit names that someone has pasted there, and marks how sure each link is (0.60 to 1.00).

Whether the date still holds

Each dated Fix Version gets a PERT confidence and a projected finish. A version with no date leaves confidence empty. It is never shown as 0% or 100%.

The chain with no slack

The longest chain of remaining work is the FLOAT 0 path. Open items on it are ranked by Severity × Occurrence × Detection. You can ask what happens if one item slips. The answer stays on the page.

A gate you can take into the release review

Each Fix Version ends as GO, CONDITIONAL, HOLD, or NO DATE. The brief is on the Slipstream page and in the issue panel. Read the gate rules.

Why not Jira Plans?

  • Jira Plans comes only with Jira Premium and Enterprise, which are bought for the whole site. Slipstream runs on Jira Cloud without that upgrade, at $4.00 per user per month after a 30-day Evaluation.
  • Plans works from dependencies people have already linked. Slipstream also infers links from issue keys written in comments and descriptions, parent and epic links across projects, and shared Fix Versions, each with a confidence.
  • Slipstream adds a PERT confidence for a Fix Version date, an FMEA score per open issue, and a Stage-Gate call.
