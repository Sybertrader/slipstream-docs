Request early access

Early access is a design-partner rollout for multi-squad organisations that share one Fix Version across projects. Email support@criticalpathworks.com with the subject “Slipstream early access”. Include the Jira Cloud site URL and the Fix Version you want to try.

Email support

Before you install

  • You need a Jira Cloud site. Slipstream is a Forge app. It does not run on Jira Data Center.
  • An admin installs it. There is no CSV, token, or setup form.
  • The first scan reads work items the app is allowed to see. It does not ask for a repository connection.
  • Until the Marketplace listing is live, access is arranged by email.

Contact

Product questions, install questions, and security reports go to the same address.

Email support

Data and privacy

Critical Path Works Ltd does not ask customers to export a database or to paste raw issue lists into email. Slipstream runs on Atlassian Forge. What is read, stored, and deleted is on the privacy and security page.

What to include

  • ✓Your Jira Cloud site URL (*.atlassian.net).
  • ✓The project keys or the Fix Version name.
  • ✓What you expected the gate, the path, or the confidence to say, and what it said instead.
